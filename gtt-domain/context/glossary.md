# Glossary

> **Canonical reference:** https://github.com/GTT-Community/gtt-method/blob/main/GTT-CANONICAL-v2.1.md

Domain terms whose meaning in this project differs from the everyday meaning, or
that are ambiguous across teams. Do not define general industry terms.

Each definition below is sourced from an already-established document in this
repository — cited in the fourth column — not invented for this table.

| Term | Meaning in this project | Not to be confused with | Source |
|---|---|---|---|
| GTT Core | The ADE-agnostic engine (`.gtt/scripts/`) that provides Artifact Identity, the Technical Index, and the Session Memory Service. Contains no ADE-specific logic. | An ADE adapter | `gtt-domain/context/architecture.md` → *Modules and boundaries*; `gtt-domain/context/principles.md` |
| ADE Adapter | Translates the Core's service output for one ADE (Claude Code, Codex, Kiro, GitHub Copilot). Owns no identity, no authority, no GTT logic. | The GTT Core itself | `.gtt/docs/docs.md` → *Session Memory adapter matrix*; `.gtt/docs/session-adapter-contract.md` |
| Artifact Identity | A stable `id`, independent of file path, kept for every governed Markdown artifact in `.gtt/index/artifacts.json`. | The file's path (a locator, not the reference) | `.gtt/docs/docs.md` → *Artifact identity and the technical index* |
| Technical Index | A derived, rebuildable accelerator (`.gtt/index/technical-index.json`) for section-level retrieval. | A source of truth, or evidence in itself | `.gtt/docs/docs.md` → *Artifact identity and the technical index* |
| Session Memory | Operational-only state (`gtt-domain/session.md`), regenerated by `gtt-session-context.sh`, describing repository state for an ADE session. | Authority, evidence, a decision record, or a grounding source | `.gtt/docs/docs.md` → *Session Memory adapter matrix*; `gtt-domain/context/principles.md` |
| Evidence | A technical claim classified as `STATIC VERIFIED`, `RUNTIME VERIFIED`, `DOCUMENTED ONLY`, or `NO EVIDENCE`, persisted in `.gtt/docs/evidence.md`. | Documentation that states something is implemented | `.gtt/docs/evidence.md` |
| Proposal | A drafted change staged under `gtt-domain/proposals/`, awaiting a Solution Designer decision. | A ratified decision | `gtt-domain/context/principles.md` ("Proposal ≠ decision"); `AGENTS.md` → *Change requests* |
| Ratification | The Solution Designer's explicit decision that a proposal (e.g. an ADR) is accepted. | The agent preparing a promotion package, which is not itself approval | `AGENTS.md` → *Human Promotion Boundary* |
| Freeze | The marker `gtt-domain/.frozen`, written by `gtt-freeze.sh`, that switches `gtt-domain/context/` and `gtt-domain/adr/` from agent-writable to read-only. | Committing code, or any other governance act | `AGENTS.md` → *Governed regime*; `.gtt/scripts/gtt-freeze.sh` |
| Scaffold | The canonical layout of a GTT workspace, declared in `.gtt/scaffold/manifest.yaml`: the Engine (`.gtt/`: machinery, derived state and GTT's own documentation), the domain (`gtt-domain/`), and one ADE overlay. | A per-ADE template — ADEs only add an overlay to the one scaffold | `.gtt/scaffold/manifest.yaml`; `AGENTS.md` → *Required workspace* |
| Engine | GTT-Method's own directory `.gtt/`: the machinery (`scripts/`, `session-adapters/`), the state it derives (`index/`, `protection/`), the scaffold manifest (`scaffold/`) and GTT's own documentation (`docs/`). It holds no architectural authority (nothing in it is a governed decision). | The domain (`gtt-domain/`), or GTT Core (the ADE-agnostic part of the Engine's scripts) | `.gtt/scaffold/manifest.yaml`; `.gtt/docs/docs.md` → *The governed domain (`gtt-domain`)* |
| Domain (`gtt-domain`) | GTT-Method's definition of the project or domain it governs: the contextual, governed space `gtt-domain/` (`context/`, `adr/`, `proposals/`, `backlog.md`, `change-request.md`, `session.md`, `.frozen`) over which GTT applies the method. Architectural authority (L0/L1) lives in it; it holds no executable GTT logic in operation — its `proposals/` holds governed drafts, including promotion scripts, that neither the domain nor an agent executes. | The Engine (`.gtt/`), or the code the project builds (L3), which belongs to neither | `.gtt/scaffold/manifest.yaml`; `.gtt/docs/docs.md` → *The governed domain (`gtt-domain`)*; `gtt-domain/adr/ADR-004-gtt-domain-and-dot-gtt-engine.md` |
